TranslationsПереводы

Language files made by the community. Download one, load it in the app, done. No update and no rebuild needed. Языковые файлы от сообщества. Скачайте, загрузите в приложении, готово. Ни обновления, ни пересборки не нужно.

How to useКак пользоваться
  1. Download an .xml file below. Скачайте файл .xml ниже.
  2. In the app open Settings → Language → Custom. В приложении откройте Настройки → Язык → Свой.
  3. Tap Load translation and pick the file. Нажмите Загрузить перевод и выберите файл.

Strings a file does not cover stay in the built-in language, so a partial translation works too. Строки, которых нет в файле, остаются на встроенном языке, так что частичный перевод тоже работает.

Start from the templateНачните с шаблона

The best template comes from your own build: Settings → Language → Custom → Save template. It always matches the version you have installed. Translate the text between the tags, keep the name attributes and placeholders such as %1$s untouched. Лучший шаблон берётся из вашей сборки: Настройки → Язык → Свой → Сохранить шаблон. Он всегда соответствует установленной версии. Переводите текст между тегами, атрибуты name и подстановки вида %1$s не трогайте.
